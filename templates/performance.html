Method in brief

Features used: {{ m.features|join(', ') }}. The charges column was left out on purpose: it is only known after a claim happens, so using it would let the model cheat. Region was dropped because it has almost no link to claims.

The data was split 80/20 with the same share of claims in both parts. Models were chosen using only the training part; the test part was used once at the end.

Limits

The dataset is small ({{ m.train_rows + m.test_rows }} rows), and the very high score suggests the data follows clear patterns that real-world data may not. Treat this as a demonstration, not a tool for real decisions.
